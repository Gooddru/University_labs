# Проверка изоморфности строк

[`solution/isomorphic_strings.cpp`](./solution/isomorphic_strings.cpp) проверяет, являются ли две строки изоморфными. Строки считаются изоморфными, если каждому символу первой строки можно однозначно сопоставить символ второй строки, сохраняя порядок повторений.

Для проверки используются две хеш-таблицы: одна хранит соответствия символов первой строки символам второй, а другая не позволяет двум символам первой строки соответствовать одному символу второй. Если длины строк различаются или найдено противоречивое соответствие, программа возвращает `false`.

Программа также содержит набор тестов с `assert` и обрабатывает пары строк из входного файла, записывая результаты в выходной файл.

## Асимптотика

- Временная сложность: `O(N)` в среднем, где `N` — длина строк. Каждый символ обрабатывается один раз.
- В худшем случае для `unordered_map` временная сложность может составить `O(N²)` из-за коллизий хеш-функции.
- Дополнительная память: `O(K)`, где `K` — количество различных символов в строках; в общем случае `O(N)`.

Пример:

```text
Строки:  egg и add
Результат: true
```
