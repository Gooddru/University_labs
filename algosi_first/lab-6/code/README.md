# Максимальная сумма трёх подмассивов

[`solutions/max_sum_subarrays.cpp`](./solutions/max_sum_subarrays.cpp) решает задачу LeetCode [689. Maximum Sum of 3 Non-Overlapping Subarrays](https://leetcode.com/problems/maximum-sum-of-3-non-overlapping-subarrays/). Требуется найти три непересекающихся подмассива длины `k` с максимальной общей суммой. Функция возвращает начальные индексы найденных подмассивов.

Для каждого возможного положения среднего подмассива заранее вычисляются лучшие варианты слева и справа. Скользящее окно позволяет быстро находить суммы подмассивов длины `k`, а префиксные суммы используются для вычисления суммы среднего подмассива.

При одинаковых суммах выбор индексов определяется сравнениями в коде: для префиксных максимумов используется строгое `>`, а для суффиксных — `>=`.

## Асимптотика

- Временная сложность: `O(N)`, где `N` — длина массива. Все проходы по массиву линейные.
- Дополнительная память: `O(N)` для массивов префиксных и суффиксных максимумов, а также накопительных сумм.
- Алгоритм предполагает, что `N >= 3K`, где `K` — длина каждого подмассива.

Пример:

```text
Массив:  1 2 1 2 6 7 5 1
k:       2
Ответ:   [0, 3, 5]
```
