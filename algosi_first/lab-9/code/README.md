# Самая длинная последовательность чётных чисел

В папке находятся следующие файлы:

- [`solutions/even_sequence.py`](./solutions/even_sequence.py) — содержит функции для построения булевой маски чётных чисел и поиска длины самой длинной непрерывной последовательности чётных элементов.
- [`tests/test_even_sequence.py`](./tests/test_even_sequence.py) — набор модульных тестов `unittest` для проверки решения на пустых, положительных, отрицательных, смешанных массивах и массивах большого размера.

Функция `longest_even_sequence` преобразует входные данные в массив NumPy, создаёт маску чётности, находит границы последовательностей с помощью `np.diff` и возвращает максимальную длину последовательности, начинающейся с чётного элемента. Если массив пустой или не содержит чётных чисел, возвращается `0`.

## Асимптотика

- Временная сложность: `O(N)`, где `N` — количество элементов массива. Все операции над массивами NumPy выполняются за линейное время.
- Дополнительная память: `O(N)` для булевой маски, индексов границ и длин последовательностей.

## Пример

```text
Ввод:  1 2 4 6 1 3 8 10 12
Вывод: Самая длинная последовательность четных чисел в введенном массиве: 3
```
