# Кластеризация массива

В папке находятся следующие файлы:

- [`algorithms/clustering.cpp`](./algorithms/clustering.cpp) — содержит вычисление метрики кластера, полный перебор разбиений массива, поиск оптимального разбиения, печать кластеров и тесты.
- [`apps/clustering_main.cpp`](./apps/clustering_main.cpp) — запускает тесты, считывает количество кластеров и элементы массива, после чего выводит найденное разбиение.
- [`tests/clustering_tests.hpp`](./tests/clustering_tests.hpp) — содержит объявления функций кластеризации и тестирования.

Для каждого кластера вычисляется сумма абсолютных отклонений элементов от его среднего значения. Функция `findClusters` рекурсивно строит все возможные разбиения массива не более чем на `K` непустых кластеров. Затем `findOptimalClusters` выбирает разбиение с минимальной суммарной метрикой.

## Асимптотика

Обозначим через `P(n, K)` количество разбиений `n` элементов на не более чем `K` непустых кластеров.

- `calculateMetric`: время `O(m)`, где `m` — размер кластера; дополнительная память `O(1)`.
- `findClusters` и `findOptimalClusters`: время `O(n · P(n, K))`, так как для каждого разбиения вычисляется метрика всех его элементов.
- `findClusters` и `findOptimalClusters`: память `O(n · P(n, K))`, потому что все найденные разбиения сохраняются в `allClusters`.
- Грубая верхняя оценка для полного перебора: время и память `O(n · K^n)`.
- `main`: хранение входного массива требует `O(n)` памяти. `findOptimalClusters` вызывается дважды, но это не меняет асимптотический порядок, который остаётся `O(n · P(n, K))`.

Пример:

```text
Количество кластеров: 2
Массив: 1 2 3 4 5 6
Результат: [ 1 2 3 ] [ 4 5 6 ]
```
