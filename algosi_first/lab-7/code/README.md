# Минимальное число за `k` обменов

[`solutions/minimum_integer_after_swaps.cpp`](./solutions/minimum_integer_after_swaps.cpp) решает задачу LeetCode [1505. Minimum Possible Integer After at Most K Adjacent Swaps On Digits](https://leetcode.com/problems/minimum-possible-integer-after-at-most-k-adjacent-swaps-on-digits/). Требуется найти минимальное число, которое можно получить из строки цифр `num`, выполнив не более `k` обменов соседних символов.

Алгоритм работает жадно: для каждой позиции ищется наименьшая цифра в пределах доступного количества обменов. Найденная цифра сдвигается на текущую позицию последовательностью соседних обменов, а `k` уменьшается на число выполненных перемещений. Если оставшегося количества обменов достаточно для полной сортировки, строка сортируется обычной сортировкой.

## Асимптотика

- Временная сложность: `O(N²)` в худшем случае, где `N` — длина строки. Поиск подходящей цифры и её сдвиг могут занимать линейное время для каждой позиции.
- Ветка с полной сортировкой выполняется за `O(N log N)`, что не превышает общую квадратичную оценку.
- Дополнительная память: `O(N)`, так как строка передаётся в функцию по значению и хранит изменяемую копию входных данных.

Пример:

```text
Число: 4321
k:     4
Ответ: 1342
```
