# Поиск начала палиндрома

 [`solution/palindrome.cpp`](./solution/palindrome.cpp) получает из стандартного ввода строку и находит индекс, с которого начинается самый длинный палиндромный суффикс строки.

Для проверки используются символы с двух концов последовательности: если они совпадают, указатели сдвигаются к центру. Если проверка не пройдена, алгоритм переходит к следующему индексу. Если подходящий суффикс не найден, программа выводит `-1`.

## Асимптотика

- Временная сложность: `O(N²)` в худшем случае, где `N` — длина строки. Для каждого возможного начала проверяется суффикс.
- Дополнительная память: `O(N)`, так как строка передаётся в функции по значению и копируется. Без копирования строки алгоритму достаточно `O(1)` дополнительной памяти.

Пример:

```text
Ввод:  plip
Вывод: 3
```
