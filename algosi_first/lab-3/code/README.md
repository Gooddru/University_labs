# Перемешивание массива

В папке находятся следующие файлы:

- [`apps/shuffle_array_main.cpp`](./apps/shuffle_array_main.cpp) — запускает тесты, считывает размер и элементы массива, перемешивает массив и выводит результат.
- [`algorithms/shuffle_array.cpp`](./algorithms/shuffle_array.cpp) — содержит реализацию перемешивания массива алгоритмом Фишера — Йейтса, функцию обмена элементов и тесты.
- [`algorithms/shuffle_array.hpp`](./algorithms/shuffle_array.hpp) — содержит объявления функций перемешивания и тестирования.

Алгоритм Фишера — Йейтса проходит по массиву справа налево. Для каждого элемента случайно выбирается индекс от `0` до текущего индекса, после чего элементы меняются местами. В результате каждый элемент остаётся в массиве, но его позиция может измениться.

## Асимптотика

- `shuffleArray`: временная сложность `O(N)` в лучшем, среднем и худшем случаях, где `N` — размер массива.
- `shuffleArray`: дополнительная память `O(1)`, не считая генератор случайных чисел; перемешивание выполняется на месте.
- `testShuffle`: временная сложность `O(N²)`, так как для каждого элемента выполняется линейный поиск в перемешанном массиве.
- `testShuffle`: дополнительная память `O(N)` для копии массива.
- `main`: ввод и вывод массива занимают `O(N)` времени, а сам массив требует `O(N)` памяти.

Пример:

```text
Ввод:  5
	1 2 3 4 5
Вывод: один из вариантов перестановки, например 3 1 5 2 4
```
