# Алгоритмы сортировки

В папке находятся три реализации сортировки:

- [`algorithms/sorting/bucket_sort.cpp`](./algorithms/sorting/bucket_sort.cpp) — сортировка по бакетам для массива чисел с плавающей точкой. Внутри каждого бакета используется сортировка вставками.
- [`algorithms/sorting/cycle_sort.cpp`](./algorithms/sorting/cycle_sort.cpp) — циклическая сортировка массива целых чисел с минимальным количеством операций записи.
- [`algorithms/sorting/heap_sort.cpp`](./algorithms/sorting/heap_sort.cpp) — пирамидальная сортировка массива целых чисел с использованием бинарной кучи.

Каждый файл содержит функцию сортировки, проверку отсортированности массива, набор тестов и `main`, который считывает массив и выводит результат.

## Асимптотика

### Bucket Sort

- Поиск минимума и максимума, распределение по бакетам и сборка массива занимают `O(N)` времени.
- Сортировка вставками внутри бакетов занимает `O(N)` в среднем при равномерном распределении элементов и `O(N²)` в худшем случае, если элементы попадают в один бакет.
- Лучшая временная сложность: `O(N)`, средняя: `O(N)`, худшая: `O(N²)`.
- Дополнительная память: `O(N)` для бакетов.

### Cycle Sort

- Временная сложность: `O(N²)` в лучшем, среднем и худшем случаях, поскольку для каждого элемента выполняется поиск его позиции.
- Дополнительная память: `O(1)`, сортировка выполняется непосредственно в исходном массиве.

### Heap Sort

- Построение кучи занимает `O(N)`, сортировка элементов — `O(N log N)`.
- Временная сложность: `O(N log N)` в лучшем, среднем и худшем случаях.
- Дополнительная память: `O(1)`, не считая стека рекурсивных вызовов `heapify`; глубина стека составляет `O(log N)`.

Пример:

```text
Ввод:  5
	4 1 5 2 3
Вывод: 1 2 3 4 5
```
